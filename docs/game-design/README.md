# Edonism — game-design documentation

Questa cartella separa **il contenuto del regolamento stampato** dalle scelte di implementazione.

1. [Indice delle fonti](rulebook-source-index.md): pagine e precedenza.
2. [Baseline delle regole](rules-baseline.md): estrazione ragionata della versione stampata, con indicazioni di pagina.
3. [Questioni aperte](open-questions.md): differenze tra le versioni, ambiguità, decisioni ancora da validare.

**Importante:** non è stato approvato né implementato un nuovo rule set digitale. Lo scopo iniziale è preservare le regole originali e la loro provenienza; un gioco web potrebbe richiedere decisioni UX e di rete aggiuntive che vanno versionate con issue separate.

Gli archivi originali sono stati forniti nella conversazione sotto forma di `rulebook2.zip`, `document.pdf`, `poteri italiano.pdf`, `plancia di gioco.png` e screenshot di cartelle immagini. In questa PR **non vengono pubblicati gli artwork/archivi binari**, né dichiarato che i singoli PNG delle carte siano già disponibili nel repository. Prima di sviluppare i cataloghi completi va garantita una copia durevole delle fonti con il corretto consenso alla pubblicazione, eventualmente in uno storage privato o Git LFS.
