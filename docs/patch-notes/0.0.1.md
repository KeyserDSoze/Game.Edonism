# Edonism 0.0.1 — Foundation

- Bootstrap monorepo with .NET 10 domain/application/infrastructure/API boundaries and xUnit.
- React + TypeScript + Vite, shadcn/ui, dark/light/system themes and Italian/English strings.
- WebGL preview with 3D hex plots, stylized code-generated figurines and an accessible tile inspector.
- Playwright smoke flows and GitHub Actions CI.
- **Not yet a playable game:** property ownership, finance, PvP, turns, content and game rules are deliberately not implemented.
