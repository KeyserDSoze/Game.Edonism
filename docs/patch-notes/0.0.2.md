# Edonism 0.0.2 — Original street board (work in progress)

- **Issue #5:** The original Edonism board is recreated as an isometric 3D city, replacing the 0.0.1 illustrative hex grid.
- Single canonical data file `src/shared/board/edonism-board.v1.json`: 7 streets, City Hall, 30 activity slots and drawn road regions. Browser and .NET read this same file.
- Read-only API endpoint `GET /api/v1/board` for public board structure.
- Domain street graph validates reachability, reciprocal connections and legal single-street adjacency, independent of 3D coordinates.
- Deterministic seed/version-based shuffle for an **already approved set of 30 activity cards**; full composition of a match's activities and mandatory starting cards is deferred to #6.
- React viewer: select 7 streets and 30 lots, inspect adjacent roads, themes and Italian/English text; DOM controls are keyboard accessible and work without WebGL.
- xUnit adjacency/graph/placement regression tests; Playwright on board selection, neighborhood, responsive, themes and i18n.
- Placeholder buildings and Pucciottini are generated by Three.js; no permanent art or live gameplay is included.

**Verification:** CI on PR #11: .NET 10 Release build with 28/28 xUnit tests (including API contract tests), frontend typecheck/bundle and 5/5 Playwright flows.

**Limits:** connections inferred from the original board image are documented for review. This milestone does not move players, grant ownership or implement the game engine. Rules source and deck assets are not published in the repository.
